# Archived TTT-Discover TriMul result

`trimul_prompt.py` is the original task prompt. `baseline_solution.py` is the
published TriMul kernel from the TTT-Discover repository at
`results/kernel-engineering/trimul.py`; `baseline_summary.md` describes that
archived result.

Source: https://github.com/test-time-training/discover

The source repository is MIT licensed. Copyright (c) 2025 Mert Yuksekgonul.
The result is kept verbatim for provenance and optional warm-start comparisons.
It is not attached to the GLM-5.2 scratch-generation prompt and is not the
default Guidance-TTT seed. The default is the independently generated frozen
library under `examples/guidance_ttt/seeds/trimul/`.

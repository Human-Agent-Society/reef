# reef-eval docs

Evaluation infrastructure for self-evolving agents, in two task regimes:
one open-ended problem (autoresearch) and an ordered stream of tasks.

Read in this order:

1. **[Get started](get-started.md)**: install, run a task and a stream,
   budgets, results, resume.
2. **[Running agents](running-agents.md)**: evaluate a supported
   harness, your own harness, or a method that is not an agent at all.
3. **[Authoring tasks](authoring-tasks.md)**: new tasks, new benchmarks,
   converters.
4. **[Metrics](metrics.md)**: the analyses over the results table.

Reference, when you need it: [design](design.md) is why reef-eval is shaped
the way it is, [glossary](glossary.md) is every term in one place, and
the [benchmark catalog](tasks.md) is what ships.

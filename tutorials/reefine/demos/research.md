# Research loop

The request `run.py research` files, the text of the fenced block below, one line:

```text
when I ask a research question or ask for sources or citations, find relevant papers on arXiv, download and read at least one, then answer with citations to what you read. Do this even for familiar facts. If I provide an arXiv URL or identifier, retrieve its abstract to check relevance first, then download and read that paper. Use existing shell tools or custom tools that wrap them. Save PDFs and extracted text under research/ in the workspace. Declare curl and pdftotext as binary requirements; PATH availability checks are sufficient. Use HTTPS, follow redirects, and bound each retrieval attempt to 30 seconds, with at most two attempts per endpoint. Semantic Scholar is optional. If you cannot retrieve and read a relevant paper, report that research is incomplete.
```

A working answer is a `rules` entry or a skill that tells the agent to search arXiv, download and read relevant papers, and cite what it read, or a `code_extension` that provides those operations. Asking for a source triggers the workflow even for a familiar fact. The arXiv path does not require an API key. The agent needs network access, `curl`, and `pdftotext` for PDF papers; the proposal declares required tools under `requires`, and `reef-pi setup` checks them before installation. Semantic Scholar is optional and must not stop the arXiv workflow.

The show session asks for the comparison-sorting lower bound and supplies `https://arxiv.org/abs/2202.01446` as a starting reference in an empty directory under `work/research-<timestamp>/workspace/`. What it should do under the change: retrieve the supplied arXiv abstract and check relevance, download at least one relevant paper into `workspace/research/`, extract and read its text, then answer with a citation (the bound is n log2 n comparisons in the worst case, up to lower order terms, from the decision tree argument). `run.py` prints the tool calls in order and the final answer. Inspect the saved files and tool results: a search attempt or a citation alone does not demonstrate that a paper was read. Publication also requires an independent review of the actual retrieval, reading and cited answer, plus health and protected-task checks. The starting URL makes this demo independent of the availability of the open-ended search API; other requests can still use that API.

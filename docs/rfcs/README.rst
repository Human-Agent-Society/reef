Deprecated historical RFCs
===========================

This directory contains RFCs created before Reef moved the RFC process to
GitHub Issues. Every RFC in this directory is deprecated and retained only as
a temporary historical reference. These files will be removed in a future
cleanup, and new RFCs must not be added here.

To propose a substantial architecture, interface, or project-policy decision,
open an `RFC issue
<https://github.com/Human-Agent-Society/reef/issues/new?template=rfc.yml>`__.
The issue body is the proposal and durable decision record. Discussion,
maintainer acceptance, material design changes, and implementation links all
stay on that issue. See `CONTRIBUTING.md <../../CONTRIBUTING.md>`__ for the
changes that require an RFC.
